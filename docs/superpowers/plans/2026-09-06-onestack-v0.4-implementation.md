# OneStack v0.4 Implementation Plan

1. Extend root/config contracts for v0.4 while preserving v0.2 compatibility.
2. Add shared normalized error package.
3. Add mobile TypeScript runtime contracts, native bridge protocol, permissions, renderer primitives, and explicit WebView fallback.
4. Add data adapter contracts plus in-memory/SQL-oriented baseline adapters and migration contracts.
5. Add auth provider/session contracts and framework guards.
6. Add storage provider contracts plus local/S3-compatible contracts.
7. Add payments provider contracts plus Stripe-oriented adapter boundary and webhook verification hooks.
8. Add deployment preset contracts for Vercel, Netlify, Cloudflare, Node, Docker, and static export.
9. Extend CLI command parsing and target awareness for mobile/service/deployment commands.
10. Add package references, tests, CI targets, universal example, and documentation.
11. Run repository CI and fix all compile/test failures before merging.

Implementation must remain backward-compatible, adapter-first, tree-shakable, explicit about unsupported platform capabilities, and server-only for secrets/privileged operations.
